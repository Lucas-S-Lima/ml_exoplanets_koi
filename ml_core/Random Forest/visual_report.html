04Como cada métrica é calculada

VP/VN/FP/FN vêm diretamente da matriz de confusão acima. As versões "macro" são a média simples entre as duas classes, dando peso igual a cada uma — importante porque a Classe 1 tem quase o dobro de amostras da Classe 0.

Precision

Precision = VPVP + FP

Das amostras que o modelo apontou como positivas, quantas realmente eram.

Recall

Recall = VPVP + FN

Das amostras realmente positivas, quantas o modelo encontrou.

F1-score

F1 = 2 × Prec × RecPrec + Rec

Média harmônica entre precision e recall — equilibra os dois.

Accuracy

Acc = VP + VNTotal

Proporção geral de acertos, sem distinguir entre classes.

Macro = (métrica classe 0 + métrica classe 1) / 2

06Número de árvores: 150 vs. 200 vs. 300

200 árvores atingiram o melhor F1 macro — a diferença para 300 árvores foi de apenas ~0,00005, não justificando o custo computacional extra.

A estimativa Out-of-Bag apontava ~300 árvores como ideal, enquanto o Grid Search com validação cruzada selecionou 200. Não há contradição: são métodos distintos de estimar o ponto ótimo, e a diferença de desempenho entre eles é praticamente desprezível.

08Conclusão

O Random Forest apresentou desempenho consistente e equilibrado entre as duas classes, com 92,46% de acurácia e F1 macro ≈ 0,92. Os erros de classificação (143 no total) ficaram distribuídos quase igualmente entre as classes — 74 falsos positivos e 69 falsos negativos — indicando que o modelo não depende exclusivamente da classe majoritária para atingir seu desempenho. A proximidade entre os resultados de validação cruzada e teste sugere boa capacidade de generalização.
